# Relent AI Examples & Recipes

This directory contains standalone, copy-pasteable Python recipes demonstrating how to integrate and use **Relent AI** programmatically.

---

## 📂 Recipes Included

| Script | Description |
| :--- | :--- |
| **[`quickstart_cli.py`](quickstart_cli.py)** | Process any YouTube or local video and export a structured Markdown report. |
| **[`generate_meeting_notes.py`](generate_meeting_notes.py)** | Extract structured action items, deadlines, owners, and decisions from meeting recordings. |
| **[`create_highlight_reel.py`](create_highlight_reel.py)** | Generate automated highlight reels from natural language prompt instructions. |

---

## 🚀 Running Examples

Ensure your virtual environment is active and dependencies are installed:

```bash
# Windows
.\.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

# Run quickstart recipe
python examples/quickstart_cli.py
```
