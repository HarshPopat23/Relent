# Getting Support for Relent AI

We want your experience with **Relent AI** to be as smooth and productive as possible! Here are the best ways to get help and connect with the community.

---

## 💬 Community Q&A & Discussions

- **GitHub Discussions**: The primary place to ask general questions, share workflows, discuss architecture ideas, and seek setup guidance.
- **GitHub Issues**: Reserved for bug reports and actionable feature proposals.

---

## 🔍 Before Asking for Help

Before opening an issue or discussion thread, please check:
1. **[Documentation Guides](docs/)**:
   - [System Architecture](docs/ARCHITECTURE.md)
   - [Hardware & Model Configuration](docs/CONFIGURATION.md)
   - [REST API Reference](docs/API_REFERENCE.md)
   - [CLI Reference](docs/CLI_REFERENCE.md)
   - [Troubleshooting & Common Errors](docs/TROUBLESHOOTING.md)
2. **Existing Issues & Discussions**: Search open and closed issues on GitHub to see if your question has already been answered.

---

## 🐛 Reporting Bugs

If you have discovered a bug:
1. Ensure you are running the latest version of Relent AI.
2. Open a new issue using our **[Bug Report Form](.github/ISSUE_TEMPLATE/bug_report.yml)**.
3. Include your operating system, Python version, Ollama model name, and full terminal tracebacks.

---

## 🛡️ Security Concerns

Please do **NOT** post security vulnerabilities in public issues. Refer to our **[Security Policy](SECURITY.md)** to report vulnerabilities responsibly.
